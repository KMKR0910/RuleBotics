# RuleBotics



>  **Ongoing Project**

RuleBotics is a Python-based **rule-driven help desk chatbot** that uses NLP preprocessing, keyword-based intent detection, synonym normalization, confidence scoring, and predefined responses.

The project is being developed incrementally, with future phases expanding it into an AI-powered help desk system.

##  Roadmap

* [x] **Phase 1** — Core Rule-Based Chatbot
* [ ] **Phase 2** — NLP & Improved Rule Engine
* [ ] **Phase 3** — Conversation & Context Management
* [ ] **Phase 4** — FastAPI & PostgreSQL Help Desk
* [ ] **Phase 5** — Authentication, Security & Testing
* [ ] **Phase 6** — Docker & Deployment
* [ ] **Phase 7** — Machine Learning Integration
* [ ] **Phase 8** — LLM & RAG Integration
* [ ] **Phase 9** — Admin Dashboard

##  Technologies

**Current:** Python, NLP, Pytest, Git/GitHub

**Planned:** FastAPI, PostgreSQL, JWT, Docker, Machine Learning, LLMs, RAG

##  Project Status

Currently developing **Phase 1**.
Features and architecture will evolve throughout the planned phases.
